# StudyFlow – AI-Assisted Development

## 1. Project Overview

StudyFlow is a React-based student study planner designed to help students organize study tasks, track completion, view schedules, manage subjects, and monitor overall progress.

The application was developed using React and Vite, with localStorage used for maintaining task data between browser refreshes.

---

## 2. AI Prompts Used During Development

AI was used as a development assistant during different stages of the implementation.

### Prompt 1 – Application Planning

> Build a React-based student study planner application called StudyFlow. The application should have a dashboard, task management, schedule, subjects, and progress sections. Suggest a suitable component structure and user flow.

### Prompt 2 – React Implementation

> Create the React implementation for the student study planner based on the required features. Include navigation between Dashboard, My Tasks, Schedule, Subjects and Progress.

### Prompt 3 – Task Management

> Add functionality to create study tasks with relevant details such as title, subject, priority and completion status. Allow users to mark tasks as completed and delete tasks.

### Prompt 4 – Data Persistence

> Implement localStorage so that study tasks remain available after refreshing the browser.

### Prompt 5 – Search and Filtering

> Add search and filtering functionality to the task section so users can find tasks and filter them according to their status or category.

### Prompt 6 – Dashboard and Progress

> Create a dashboard that displays study statistics, task information, subject progress and overall progress in a clear way.

### Prompt 7 – Debugging

> Review the React application for errors and identify problems that could prevent the application from functioning correctly.

### Prompt 8 – CSS and Layout Debugging

> Fix the CSS layout of the React application. Ensure that the sidebar does not overlap the main content and that the dashboard, cards, buttons, progress bars and other components are styled correctly.

### Prompt 9 – Responsive Design

> Make the student study planner responsive so that the interface works properly on different screen sizes.

### Prompt 10 – Final Testing

> Review the completed React application and identify functionality that should be tested before submission.

## 3. How AI Assisted During Development

AI was used as a development assistant throughout the implementation of StudyFlow.

It helped with:

- Planning the structure and functionality of the application.
- Generating and explaining React code.
- Designing the application flow and component structure.
- Implementing task management functionality.
- Implementing localStorage persistence.
- Adding search and filtering functionality.
- Creating dashboard statistics and progress tracking.
- Troubleshooting React and CSS issues.
- Explaining errors encountered during development.
- Suggesting corrections and improvements after testing.

AI-generated suggestions were reviewed and tested during development rather than being accepted without verification.

The application was manually run and tested to ensure that the implemented functionality worked as expected.

---

## 4. Manual Improvements and Corrections

After reviewing and testing the AI-assisted implementation, several manual corrections and improvements were performed.

### Layout Corrections

The initial application layout had issues where the sidebar overlapped the main content area. The CSS was manually corrected so that the sidebar and main content occupy their intended areas.

### Styling Corrections

Some elements initially appeared with default browser styling. The CSS was adjusted to provide consistent styling for:

- Buttons
- Cards
- Forms
- Task items
- Progress bars
- Navigation elements
- Statistics cards

### Progress Bar Corrections

The progress section was reviewed and the progress indicators were corrected so that they displayed properly instead of showing unwanted characters or incorrect formatting.

### Responsive Layout

Responsive CSS rules were reviewed and adjusted so that the application adapts to smaller screen sizes.

### Functionality Testing

The application was manually tested by:

- Creating study tasks.
- Viewing tasks in My Tasks.
- Marking tasks as completed.
- Deleting tasks.
- Searching/filtering tasks.
- Navigating between application sections.
- Checking subject progress.
- Checking overall progress.
- Refreshing the browser to verify that task data persisted.
